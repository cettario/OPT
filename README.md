# КТ Оптимизация

- `courses.xml` - исходный XML с тремя курсами.
- `optimization.xsl` - три выборки с использованием XSLT-ключей: по преподавателю, по теме XML и совместно по преподавателю и теме XSLT.
- `result.html` - готовый результат (XSLT 1.0, XPath 1.0).
- `run.py` - повторное преобразование.
